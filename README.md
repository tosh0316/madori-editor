# 間取りエディタ（webapp）— スマホでシングルラインを編集 → house.json

単一ファイル `index.html`（依存なし・モバイル対応）。910グリッド上で間取り（＝シングルライン相当）を
タッチで編集し、SSOT の **house.json** を出力する。JSON は `azumino_gen/spec.py` の
`generate_from_spec` がそのまま読んで Rhino で3Dを生成できる（スキーマ互換）。

## 使い方
- 下部ツール: **外壁 / 内壁**（2点タップで作図）, **開口**（壁をタップして配置）, **床**（頂点を順にタップ→始点で閉じる）, **消去**, **戻す**, **≡メニュー**。
- 上部: **1F / 2F** レベル切替（他階は淡色破線で表示）。
- 操作: 1本指ドラッグ=パン、2本指ピンチ=ズーム、タップ=ツール実行。
- ≡メニュー: グリッド（ピッチ/通り数/半グリッド吸着）、レベル高さ、屋根（母屋の棟通り・勾配・等勾配・軒の出）、開口既定、**JSON生成/コピー/保存/取込/例読込**。

## Rhino へ渡す
1. ≡ →「生成/更新」→「コピー」or「保存」で house.json を得る。
2. その JSON を Rhino（PC）側で:
```python
import azumino_gen as az
spec = az.load_spec(r"...\house.json")     # または dict を直接
az.generate_from_spec(__rhino_doc__, spec) # grid/壁/床/開口/屋根/アセット→穴あけ→屋根で壁カット
```

## スマホからアクセス（同一Wi-Fi）
PC で:
```
python -m http.server 8777      # リポジトリ直下で実行
```
スマホのブラウザで `http://<PCのIPアドレス>:8777/webapp/index.html` を開く。
（`#demo` を付けるとサンプル間取りを読み込む。）
